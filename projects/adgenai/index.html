Project

AdGenAI

AI-powered advertisement and poster generator built during the Pravinya Infotech internship.

React.jsFlaskMongoDBGoogle GeminiImagen 3AWS S3

What it is

AdGenAI automates campaign creative generation from prompt and product input, producing theme-aligned advertisements and posters.

Problem

Marketing teams often need many creative variants quickly. Manual poster production is slow when product imagery and campaign themes change frequently.

Why it was built

The project was developed during my software engineering internship at Pravinya Infotech (January–May 2025) as a practical applied-AI product inside an agile team.

My contribution

  • Built the generation pipeline spanning React frontend, Flask backend, and MongoDB.
  • Integrated Google Gemini and Imagen 3 APIs for copy and visual generation from product imagery and prompts.
  • Implemented AWS S3-backed asset storage and API error handling for more reliable campaign reuse and review.

Important implementation details

The system treated generative model calls as an orchestration problem: prompt input, model responses, storage, and review needed a single coherent loop rather than disconnected scripts.

Challenges and learnings

Working with generative APIs taught careful error handling, asset lifecycle design, and the difference between a demo prompt and a pipeline a team can actually operate.
