Project

W3Chat.io

Conversational interface for transfers, swaps, bridges, mints, and timed on-chain jobs — built for ETHGlobal Agentic Ethereum.

Next.jsCoinbase AgentKitOnchainKitHyperlane

What it is

W3Chat.io is a chat-driven agent interface for practical Web3 actions: sends, swaps, bridging, mints, and some timed jobs across chains.

Problem

Wallet and multi-step on-chain workflows are powerful but often fragmented across UIs. A conversational agent can reduce the number of context switches if action routing is reliable.

Why it was built

Built for ETHGlobal — Agentic Ethereum (February 2025), exploring Coinbase AgentKit-oriented multi-chain agent patterns.

My contribution

  • Built the chat UI that drives on-chain actions and timed jobs.
  • Integrated AgentKit / OnchainKit for wallet actions with a simplified UX.
  • Used Hyperlane where bridging mattered in the flow.

Recognition

Recognized in the ETHGlobal Agentic Ethereum Coinbase AgentKit pool (Round 2). See the public showcase for the event write-up.
