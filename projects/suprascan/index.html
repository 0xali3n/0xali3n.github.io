Project

SupraScan

Explorer and API-key oriented query flow for Supra balances, transactions, and pools.

ReactNext.jsSupra RPCIndexer

What it is

SupraScan is an explorer for the Supra ecosystem with an API-keys flow so developers and users can query balances, transactions, and pools.

Problem

Emerging L1 ecosystems need readable explorers and simple developer query paths early — otherwise debugging and discovery stay stuck in raw RPC usage.

Why it was built

Built at the Supra Movers Hackathon (January 2025).

My contribution

  • Delivered explorer surfaces plus an API-key oriented query flow.
  • Worked with Supra RPC and indexing pieces needed for balances, transactions, and pools.

Result

Third place · $2,000 (portfolio competition records). Supra shared related launch coverage on X.
