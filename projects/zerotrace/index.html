Project

ZeroTrace

End-to-end encrypted messaging dApp MVP with privacy-first backend design and verifiable state modeling.

RustActix-webJavaScriptZK conceptsXChaCha20-Poly1305

What it is

ZeroTrace is an encrypted messaging MVP exploring privacy-first messaging state handling and verifiable state design.

Problem

Messaging systems that claim privacy need careful backend state design. Encryption alone is not enough if server-side state handling is opaque or hard to reason about.

Why it was built

To prototype encrypted messaging with a Rust backend and interfaces prepared for stronger proof-oriented modules.

My contribution

  • Architected a Rust/Actix backend for privacy-first messaging state handling.
  • Modeled Psy-style proof/state transitions for protocol-aligned integration.
  • Implemented simulated ZK/Poseidon2 modules behind swap-ready interfaces.
